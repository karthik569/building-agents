# Prior knowledge established: experienced engineer, new to agents

The material targets a professional software engineer comfortable with Python, CLIs,
testing, and HTTP, with no prior agent-building experience. The goal is a production
agent, not exploration: success is a colleague using it without the author in the room.

**Implications:** skip all programming fundamentals; assume reading a 50-line loop is
cheap, and spend the teaching budget on what is genuinely unfamiliar — control-flow
decisions, tool and ACI design, context management, evals, and failure diagnosis. Every
lab must run offline, because a lesson depending on a paid API call is unrunnable for
someone without credit.
